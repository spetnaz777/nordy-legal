# Nordy — legal

The published Privacy Policy and Terms of Use for the Nordy iOS app,
operated by SIXSIDE MARKETING INC.

Served by GitHub Pages at:

- https://spetnaz777.github.io/nordy-legal/privacy.html
- https://spetnaz777.github.io/nordy-legal/terms.html

**These URLs are baked into shipped app binaries and must not move.** The app
reads them from `src/core/legal.ts` in the main Nordy repository, and a build
already in the App Store cannot be pointed somewhere else.

The Markdown in `nordy-app/legal/` is the source of truth. These pages are
rendered from it — edit there, re-render, and push here.
